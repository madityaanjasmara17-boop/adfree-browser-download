## Cara pasang

**Windows:** buka file `.exe`, pilih folder, selesai. Jika muncul "Windows protected your PC", klik **More info → Run anyway** (installer belum ditandatangani sertifikat).

**Android:** buka file `.apk` di HP, izinkan **Install unknown apps** untuk browser atau file manager yang Anda pakai, lalu **Install**.
